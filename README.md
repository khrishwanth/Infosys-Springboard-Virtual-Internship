# InsurAI – Corporate Policy Automation

A backend-focused application for managing and automating corporate insurance policies.  
This project demonstrates role-based access, policy handling, and backend automation logic using Java and Spring Boot.

---

## 🚀 Features
- Corporate policy management
- Role-based authentication & authorization
- Secure backend APIs
- Scalable project structure
- RESTful design principles

---

## 🛠 Tech Stack
- Java
- Spring Boot
- Spring Security
- JPA / Hibernate
- MySQL
- Maven
- Git & GitHub
